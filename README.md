# مصاريفي

تطبيق Android عربي لإدارة الأموال الشخصية اليومية، يعمل Offline First ويعرض الدخل والمصروفات والرصيد والديون والتقارير بصورة واضحة.

## حالة المشروع

المشروع في مرحلة **PHASE 0 — Project Bootstrap**. المستودع بدأ بملف README فقط؛ لم يتم إنشاء تطبيق Android أو تشغيل Build أو اختبارات حتى الآن.

المرجع الأعلى لحالة التنفيذ هو [ROADMAP.md](ROADMAP.md).
